
# 📘 Atividade: Jogo da Forca em Python

## 🎯 Objetivo

Pratique manipulação de strings, loops, condicionais e entrada de dados ao implementar o jogo da Forca em Python.

## 📝 Tarefas

### 🛠️ Implementar o Jogo da Forca

#### Descrição

Crie um jogo em que o jogador tenta adivinhar uma palavra oculta, informando letras antes que as tentativas incorretas acabem.

#### Requisitos

O programa concluído deve:

- Selecionar aleatoriamente uma palavra de uma lista predefinida.
- Aceitar palpites de letras e exibir o progresso da palavra no formato `_ _ _`.
- Controlar e mostrar quantas tentativas incorretas ainda restam.
- Encerrar quando a palavra for adivinhada ou quando as tentativas acabarem.
- Exibir uma mensagem indicando vitória ou derrota.
